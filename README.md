# 少棒紀錄室｜第一階段

國小少棒球隊管理與賽事設定的 PWA 原型。

## 功能
- 球隊新增、編輯、刪除
- 球員名單管理：背號、姓名、守備位置；同隊背號重複檢查
- 賽事管理：日期、時間、對手、場地、備註
- 預設 6 局，可選 5、7、9 局；延長賽與提前結束條件可設定
- IndexedDB 本機資料儲存
- JSON 備份匯出／匯入
- Service Worker 快取，支援離線開啟

## 部署
1. GitHub Repository 設定為 GitHub Pages，來源選 Deploy from a branch。
2. Branch 選 main，資料夾選 /(root)，儲存。
3. 等待 Pages 部署完成後，首次開啟網站需有網路，讓程式快取。
4. 定期匯出 JSON 備份。

## 重要說明
- 此階段資料只存在目前瀏覽器／裝置，尚無帳號與跨裝置雲端同步。
- 不要將球員個資或比賽紀錄放入 GitHub 程式碼。
- 分差提前結束設定僅供紀錄本場採用規則，正式賽事依主辦單位競賽規程。
- 第二階段再加入逐球、打席、跑壘、守備與投手紀錄。
